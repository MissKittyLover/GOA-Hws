HTML, CSS, JS - INFO BOUT THEM

HTML:

HTML stands for HyperText Markup Language. It is the standard markup language for documents designed to be displayed in a web. HTML is the bone structure of a webpage.

CSS:

CSS stands for Cascading Style Sheets. It is used to describe the presentation of a doc written in HTML or XML. CSS is the visual appearance of a webpage.

JS:

JS stands for JavaScript. It is a programming language that is used to create interactive effects within webs. JS gives the webpage a "soul".

\

Difference among them:

HTML creates the structure of a web, CSS beautifies it and JS gives it interactivity.
